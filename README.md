# BvskCfgFileCreator

GUI-приложение на Qt Quick/QML для расчёта калибровочных коэффициентов по протоколу
измерений (текстовая таблица углов Aцу, Bцу, Aизм, Bизм) и сохранения результата
в cfg-файл (вкладка `Bvsk.cfg`, файл с расширением `.cfg`).

## Возможности

- Открытие и редактирование файлов с исходными данными (вкладки, горячие клавиши).
- Разбор таблицы чисел (пробелы — разделители, `.` или `,` — десятичный разделитель, строки с `#` — комментарии).
- Проверка синтаксиса: сообщение с номером строки и текстом ошибки, подсветка ошибочной строки красным, комментариев (`#`) — зелёным.
- Расчёт по секторам линейных калибровочных коэффициентов для поправок eps и delta.
- Сохранение содержимого вкладки в `.cfg` (расширение добавляется автоматически).
- Панель сообщений с цветовой индикацией: обычное / ошибка (красный) / успех (зелёный).
- Режимы «Calibration» / «Termocalibration»; реализован только «Calibration».

## Формат входных данных

Текстовый файл (`*.txt`) с таблицей чисел. Из каждой строки берутся первые четыре
значения — углы Aцу, Bцу, Aизм, Bизм (в коде — `Acu`, `Bcu`, `Aizm`, `Bizm`).
Строки группируются в секторы по изменению значения Bцу.

## Формат результата (cfg)

Для каждого сектора: заголовок `^Bцу`, далее по строке на узел сетки — 6 чисел
с точностью 6 знаков:

    ^<Bцу>
    <eps_вершина> <eps_гор_коэф> <eps_верт_коэф> <delta_вершина> <delta_гор_коэф> <delta_верт_коэф>

Горизонтальный коэффициент — разность поправок соседних узлов, отнесённая к длине
сектора по горизонтали (10°), вертикальный — к высоте сектора (5°).

## Технологии

C++11, Qt 5 (Qt QML/Quick, Qt Quick Controls 2 со стилем Material, Qt.labs.platform,
опционально Qt Widgets); шрифт fontello; сборка — qmake.

## Структура проекта

- `main.cpp`, `maincontroller.cpp/.h` — точка входа и контроллер (синглтон).
- `Models/` — парсер таблицы чисел (`parser.cpp`, паттерн «Посетитель»), класс угла
  ±180° (`angle.cpp`), расчёт коэффициентов (`cl_algorithms.cpp`), структуры данных
  (`io_structs.h`), заготовка проверки cfg (`checkercfg.cpp`).
- `GUI/` — формы (`main.qml`, `doc.qml`), документ и подсветка (`documenthandler.cpp`),
  панель сообщений (`errorshandle.cpp`), компоненты вкладок (`GUI/qml/`).

## Сборка

    qmake BVSKCfgFileCreator.pro
    make

(или открыть `BVSKCfgFileCreator.pro` в Qt Creator).
